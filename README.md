# Loading Screen Animation

A simple loading screen built using HTML and CSS. This project recreates a clean loading interface with a rotating spinner animation and centered message layout. It was created as a practice project to improve understanding of CSS animations, positioning, and component styling.

## Learning Outcomes

* Structuring web pages using semantic HTML
* Applying Flexbox for layout and centering
* Creating CSS-based loading animations
* Using CSS keyframes and transforms
* Organizing styles with reusable class naming conventions

## Project Outcome

Successfully built a responsive loading screen featuring:

* Centered loading message
* Author attribution text
* Animated circular spinner
* Clean and minimal user interface

This project serves as a small experimental/demo project for practicing front-end fundamentals and CSS animation techniques.

## Tech Stack

* HTML5
* CSS3
